# Neural-Network-with-TensorSlow
Here is a Neural Network I wanted to create with TensorSlow, an educational self made framework inspired by TensorFlow. 
It's a reworked example from the university course "Build Your Own Neural Network".

Additional: In the "Vision Transformer" branch I added a Vision Transformer based on the paper 
"An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale" adjusted to the TensorSlow framework.
